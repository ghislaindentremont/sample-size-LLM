Wilson score vs. Clopper-Pearson exact

  
Both methods test H₀: p ≤ p₀ against H₁: p > p₀ and share the same decision rule: reject H₀ if the number of acceptable responses X ≥ c, where c is the critical count derived from p₀, N, and α.

  
Wilson score (recommended for planning) uses a normal approximation. The sample size formula is closed-form:

  
N = ⌈ ( z_α · √(p₀q₀)  +  z_β · √(p₁q₁) )² / (p₁ − p₀)² ⌉

  
The approximation is reliable when N·(1 − p₀) ≥ 10 — for p₀ = 0.90 this means N ≥ 100, a condition met by all sample sizes recommended for 80% power at proportions typical in LLM evaluation. Wilson score is the standard modern recommendation for proportion intervals and sample size planning.[1][2][3]

  
Clopper-Pearson exact evaluates P(X ≥ c | Bin(N, p)) directly, with no approximation. The type I error is guaranteed at or below α (achieved α is typically slightly below nominal due to the discreteness of the binomial). Use CP when the required N falls below 100, or when a strict type I error guarantee is required.






  
Assumptions

  

    
Responses are independent.
Each judgment is a separate, independent Bernoulli trial. Multiple responses to the same prompt violate independence and reduce effective N below the nominal count. These formulas will overstate power if responses are clustered by prompt — use the clustered design tab in that case.

    
The rubric is fixed before data collection.
Acceptable/not-acceptable criteria must be defined and locked before any responses are seen. Post-hoc rubric changes make the observed rate uninterpretable.

    
Prompts are a representative sample from the target population.
If your prompts are easier or differently distributed than real-world queries, the estimated rate applies to your prompt set, not deployment traffic.

    
N is fixed before data collection.
Sequential stopping or interim analyses alter the type I error unless explicitly accounted for.

    
Judgments are accurate.
Rater disagreement shifts the observed proportion. Measure and report inter-rater agreement separately.

When responses are clustered by prompt

  
If the same prompt is answered k times, those k judgments are not independent: a hard prompt tends to fail every time and an easy one to pass every time. Each prompt i has its own acceptable rate pi, and its responses share it. Statistically, pi ~ Beta(a, b) and Xi | pi ~ Binomial(k, pi) — the Beta-Binomial model. Two numbers summarise it: the mean rate μ = a/(a+b), which is what the test is about, and the between-prompt correlation ρ = 1/(a+b+1), which measures how much prompts differ in difficulty.[9]

  
Clustering inflates the variance of the pooled proportion by the design effect, or variance inflation factor:[4][5][6]

  
VIF = 1 + (k − 1)·ρ

  
so n·k judged responses carry only n·k / VIF responses' worth of information. The calculator plans with the Wilson score test of the first tab, with the null standard error multiplied by √VIF:

  
N_iid  = ( z_α·√(p₀q₀) + z_β·√(μ₁q₁) )² / (μ₁ − p₀)²   responses needed if independent
n      = ⌈ VIF · N_iid / k ⌉                            prompts;   N = n·k total responses
power  = Φ( ( (μ₁ − p₀)·√(N/VIF) − z_α·√(p₀q₀) ) / √(μ₁q₁) )
reject H₀ if  X ≥ ⌈ N·p₀ + z_α·√(N·p₀q₀·VIF) ⌉

  
ρ is treated as a known planning value. With k = 1, VIF = 1 for any ρ and everything reduces to the one-proportion tab. The "naive" column in the result panel shows what the one-proportion formulas would claim for the same design, and what they would actually deliver: the naive test's true false-positive rate is 1 − Φ(z_α/√VIF), not α.






  
Design takeaways

  
    
    
  1. Prefer new prompts over repeated responses. For a fixed number of judged responses, every response spent re-asking a prompt buys less information than a response on a new prompt (VIF ≥ 1). k = 1 maximises power, for any ρ.
    2. 
    
  2. With one response per prompt the simple test is exactly valid. Each outcome is then an independent draw with probability μ, however widely prompt difficulty varies. Nothing needs correcting.
    3. 
    
  3. If you repeat prompts and ignore it, the false-positive rate rises to 1 − Φ(z_α/√VIF). How much depends on ρ: with k = 5, a nominal 5% test really runs at 6.7% when ρ = 0.05 but at 17% when ρ = 0.5. Prompt pools dominated by always-pass / always-fail prompts (large ρ) are where the naive test fails badly; when difficulty clusters near the mean (ρ ≲ 0.05) the inflation is modest.
    4. 
    
  4. Repeating prompts pays only when new prompts are expensive and difficulty is homogeneous. If a new prompt costs c responses to create, the cost-optimal number of responses per prompt is[7][8]
      
    k* = √( c · (1 − ρ) / ρ )
    
      For c = 10: k* ≈ 14 when ρ = 0.05, ≈ 3 when ρ = 0.5, ≈ 1.4 when ρ = 0.83. Enter c above and the result panel reports k*.
    5. 
  






  
Choosing ρ

  
ρ is the correlation between two judgments of the same prompt — equivalently, the share of outcome variance that comes from prompts differing in difficulty. For a Beta(a, b) spread of difficulties, ρ = 1/(a+b+1). Rules of thumb:

  

    
ρ = 0
Every prompt equally hard. Pure binomial; rarely realistic.

    
ρ ≈ 0.02–0.1
Difficulty varies but most prompts sit near the mean. Beta(38, 2) gives ρ = 0.024; Beta(19, 1) gives 0.048. Typical for curated question sets with a graded rubric.

    
ρ ≥ 0.5
Most prompts are effectively always-pass or always-fail. Beta(0.95, 0.05) gives ρ = 0.5. Typical for deterministic tasks, low-temperature sampling, or pass/fail unit-test style grading.

  

  
From pilot data with k responses per prompt, estimate ρ by fitting a Beta-Binomial model (e.g. R glmmTMB(cbind(y, k − y) ~ 1, family = betabinomial); ρ̂ = 1/(1 + φ̂)) or with the ANOVA estimator.[9] When unsure, plan with a larger ρ — it is the conservative choice.






  
Assumptions

  

    
Every prompt gets the same k responses.
With unequal k, use the harmonic mean of k; the result is slightly conservative.

    
Responses to a prompt are independent given the prompt.
Shared conversation history, caching, or near-zero temperature make responses more alike than ρ allows and understate the true VIF.

    
ρ is a planning constant.
The analysis of collected data should estimate it (Beta-Binomial regression); realised power is then a little below the planned value. Set the target power a few points above the minimum you need.

    
N is large enough for the normal approximation.
Require N·(1 − p₀)/VIF ≥ 10 — for p₀ = 0.90, at least 100 effective responses (N/VIF). Below roughly 60 effective responses, model-based analyses of the collected data (a Beta-Binomial fit with a Wald test) become markedly conservative and often fail to converge; plan above that floor.

    
All one-proportion assumptions still apply.
Fixed rubric, prompts sampled from the target distribution, N fixed in advance, accurate judges.
