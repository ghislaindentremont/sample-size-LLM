Power vs. sample size

What is being tested

Let p be the true probability that a response from this model, on this task distribution, is judged acceptable. The test asks whether the data are inconsistent with the model performing at or below the threshold:

H₀: p ≤ p₀   versus   H₁: p > p₀

You judge N responses and count the acceptable ones, X. H₀ is rejected when X is at least the critical count shown in the result panel. The expected proportion p₁ is not tested; it is the alternative you plan around, and power is the probability of rejecting H₀ if p is truly p₁.

Assumptions that make this test valid

Each judgment is binary and the rubric is fixed in advance.
Every response is acceptable or not, by criteria decided before any responses are seen. Changing the rubric after looking at outputs makes the observed rate uninterpretable.
Responses are independent.
One response per prompt, from prompts that do not share content. Multiple samples of the same prompt, paraphrased duplicates, or multi-turn responses from one conversation are correlated: they count as fewer than N independent trials and inflate the false-positive rate.
The prompts are a random sample from the distribution you want to make a claim about.
The test estimates one proportion for one population. If your prompts are easier, narrower, or differently mixed than deployment traffic, p refers to your prompt set, not to the deployment.
N is fixed before data collection.
Decide the sample size here and judge all N responses. Stopping early once the count looks good, or adding responses when it does not, raises the true α above the nominal value.
Judgments are accurate.
The test treats each label as the truth. A human or LLM judge that mislabels some responses shifts the observed rate; if the judge is lenient, you can pass the threshold without deserving to. Measure judge agreement separately.
The question is one-sided.
You want evidence that performance exceeds p₀ and would not act on evidence that it is lower. A non-significant result does not show performance is below p₀; it only fails to show it is above.
Score/CC methods only: N is large enough.
The z-tests need both N·p₀ and N·(1−p₀) to be at least about 10. With thresholds near 1, such as 0.90, the failure count is small and the approximation is poor below roughly N = 100. The exact test has no such requirement.

How the numbers are computed

These are analytic calculations — not Monte Carlo simulations. Every number on this page comes from evaluating a closed-form mathematical expression or summing an exact probability distribution. No random experiments are simulated. A Monte Carlo power study would instead repeatedly generate fake datasets, run the test on each, and count how often it rejects; the analytic approach gives the same answer directly from the binomial distribution, in milliseconds and without sampling error.

Exact binomial. Under H₀ at the boundary (p = p₀), the count of acceptable responses follows X ~ Binomial(N, p₀). The critical count c is the smallest integer satisfying P(X ≥ c | p₀) ≤ α. Power is P(X ≥ c | p₁). Both tail probabilities are computed by summing binomial terms exactly, using a log-space recurrence to avoid underflow at large N. For sample size, N is the smallest value whose power reaches the target — found by scanning N = 1, 2, 3, … and stopping at the first hit. Because binomial probabilities are discrete, the achieved α is strictly at most the nominal α, and power does not increase smoothly with N; the sawtooth in the chart and the nearby-N table both show this.

Score (Wilson) z-test. The score test uses the standard error evaluated under the null hypothesis proportion p₀ — not under the sample estimate p̂ as the Wald test does. Rejecting H₀ by the score test is exactly equivalent to the one-sided Wilson score confidence lower bound on p exceeding p₀. This equivalence is why your intuition was right: the Wilson interval is superior to Wald near 0 and 1 precisely because it evaluates uncertainty at p₀ rather than at an extreme p̂, and the same logic applies to the test. A Wald test is not offered here because the score test is uniformly better for the parameter values relevant to LLM evaluation (thresholds ≥ 0.80).

The formulas, with zα and zβ denoting upper standard-normal quantiles:

N     = ⌈ ( (z_α·√(p₀(1−p₀)) + z_β·√(p₁(1−p₁))) / (p₁ − p₀) )² ⌉
power = Φ( ( (p₁ − p₀)·√N  −  z_α·√(p₀(1−p₀)) ) / √(p₁(1−p₁)) )
crit  = ⌈ N·p₀ + z_α·√(N·p₀(1−p₀)) ⌉

Score z-test + continuity correction. The binomial is a discrete distribution approximated by a continuous normal. The continuity correction applies a ½ adjustment to bridge them: the critical count becomes ⌈N·p₀ + zα·√(N·p₀(1−p₀)) + ½⌉, making it harder to reject and keeping the true Type I error closer to the nominal α. Power at p₁ is then computed from this corrected critical count using a normal approximation on the alternative side. For sample size, the closed-form score formula provides a starting point; a short search upward finds the first N at which corrected power meets the target (typically the same N or one or two larger). At large N the correction is negligible; it matters most below N ≈ 200. The corrected test tracks the exact result more closely than the plain score test.

The two score methods converge toward the exact result as N grows. When they disagree, the exact result is the one to report in a publication, because it makes no approximation.

All computation runs in your browser; nothing is sent anywhere. When reporting results, include the method, p₀, p₁, α, N, and the critical count so the study can be reproduced exactly.
